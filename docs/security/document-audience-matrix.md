## What the inspected implementation does and does not show

- `backend/app/schemas/document.py` defines a generic export body with `metadata`, `sections`, paragraph/table/transcript/reflection blocks and three document types. It has no explicit intended audience, recipient, disclosure purpose, release approval or allowed-field policy.
- `backend/app/api/routes/documents.py` protects the route with the configured authentication dependency and hands the supplied content to the renderer. This rendering path is not, by itself, a policy determining who should receive the completed artifact. Independently test object ownership and export history attribution in the security suite.
- `backend/app/services/document_export.py` deliberately supports reflections and transcripts. Preserving those blocks is appropriate for existing reviewed uses; removing them globally would change clinical meaning and is not an authorized security cleanup.
- `backend/app/graph/supervision_report.py` carries review status and clinical uncertainty. These are useful provenance controls but do not authorize release to a different audience.
- `backend/test_document_rich_text.py` and `backend/test_supervision_form.py` are existing regression anchors; this documentation task did not rerun them. `backend/test_auth_guard.py` and `backend/test_persistence_workflow.py` use offline/mocked boundaries. Refer to the progress log for exact passing runs and newly added independent tests. Hosted database policies and real recipients remain unverified.

The distinction between a process note and a service record is an operational proposal for this product. It is not a transplant of a foreign legal category or a blanket reason to refuse a Korean data-subject access request. Resolve access, mixed-person records, emergencies and legally compelled disclosures with the custodian and appropriate experts.

No confidential source excerpts, real counseling materials, credentials or interview identities are included. This change is documentation only; no source data or synthetic accounts require cleanup.
