# Re:mind Product Spec

## 1. 제품 정의

Re:mind는 정신건강 상담사를 위한 상담 이후 문서화 워크스페이스입니다.

상담사 메모, 축어록/STT 텍스트, 이전 회기 요약을 구조화된 회기요약 초안으로 변환합니다. 또한 상담사가 어떤 부분이 입력 근거에 기반한 내용인지, 어떤 부분이 모델 추론인지, 어떤 부분이 민감정보 후보인지, 어떤 부분이 상담사 검토가 필요한 영역인지 확인할 수 있도록 검증 리포트를 제공합니다.

## 2. 문제

상담사는 동일한 상담 사례를 여러 문서 형식으로 반복해서 재구성해야 합니다.

대표적인 문서는 다음과 같습니다.

- 회기 기록
- 회기요약
- 슈퍼비전 보고서
- 종결 보고서
- 기관 양식

문제는 문서 하나를 작성하는 데서 끝나지 않습니다. 더 큰 부담은 같은 사례를 서로 다른 목적, 길이, 형식에 맞게 반복적으로 압축하고 재구성해야 한다는 점입니다.

## 3. 대상 사용자

초기 대상 사용자는 다음과 같습니다.

- 회기요약을 자주 작성하는 상담사
- 슈퍼비전 보고서를 준비하는 수련 상담사
- 클로바노트, GPT, Gemini 등을 조심스럽게 활용하고 있는 상담사
- 상담 문서화 지원을 원하지만 임상적 판단은 본인이 통제하고 싶은 상담사

## 4. 제품 포지셔닝

Re:mind는 상담 이후 문서화에 집중합니다.

Re:mind가 집중하지 않는 영역은 다음과 같습니다.

- 실시간 상담 개입
- 상담사 수행 평가
- 완전 자동 사례개념화
- AI 슈퍼비전
- 상담 대체

## 5. 핵심 차별점

1. 근거 추적형 생성
   - 생성된 내용은 상담사 메모, 축어록, 이전 회기 요약, 모델 추론 중 어디에서 나온 것인지 연결됩니다.

2. Human-in-the-loop 편집
   - 상담사가 최종 기록을 직접 검토, 수정, 확정합니다.

3. 상담 문서화 특화 흐름
   - 회기요약과 문서 변환에 맞춰진 제품 구조를 제공합니다.

4. 저장 최소화 MVP
   - MVP V1은 요청별 처리 기본값을 유지하되, `persist=true`와 Supabase 설정이 있을 때만 demo/synthetic 기록을 저장합니다.

5. 상담사 판단 경계 명시
   - 임상적 판단이 필요한 영역은 상담사 검토 대상으로 표시합니다.

## 6. 업데이트된 MVP 방향

기존 MVP는 상담사 메모, 축어록/STT, 이전 회기 요약을 입력받아 구조화하고 회기요약 초안과 검증 리포트를 생성하는 흐름에 집중했습니다.

업데이트된 MVP는 상담사가 이미 사용하는 도구, 예를 들어 클로바노트, STT, GPT 이후 단계에 붙는 문서화 워크스페이스를 지향합니다.

핵심 방향은 다음과 같습니다.

- 상담 특화 회기요약 초안 생성
- 원문 근거, AI 추론, 상담사 확인 필요 영역 분리
- 상담사 수정 및 확정 흐름 제공
- 확정된 회기요약을 기반으로 슈퍼비전 보고서, 종결 보고서 등으로 확장
- `case_id` 기반 이전 회기 기억, 문서 양식 KB, 개인정보/윤리/보안 KB를 retrieval로 연결

## 7. 제품 원칙

- AI는 상담사를 대체하지 않습니다.
- AI는 위험 신호를 최종 판단하지 않습니다.
- AI는 상담사 평가 도구가 아닙니다.
- 생성된 초안은 상담사 검토 전 최종 기록으로 사용되지 않습니다.
- 상담사가 수정하고 확정한 내용만 최종 회기 기록으로 간주합니다.
