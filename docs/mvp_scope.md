# MVP Scope

## 1. MVP V0 목표

MVP V0의 목표는 핵심 상담 문서화 흐름을 데모 수준으로 완성하는 것입니다.

```text
Session Input
  ↓
Input Sanitization
  ↓
Session Structuring
  ↓
Evidence Mapping
  ↓
Session Summary Draft
  ↓
Verification Report
  ↓
Counselor Edit and Confirm
```

상담사가 상담 직후 자료를 입력하면 AI가 이를 공통 중간 구조로 정리하고, 회기요약 초안을 생성한 뒤, 검증 리포트를 통해 상담사가 확인해야 할 부분을 표시합니다.

## 2. MVP V0 포함 범위

### 2.1 회기 입력

필수 입력:

- 케이스 ID 또는 가명
- 회기 번호
- 회기 날짜
- 상담자
- 상담사 메모
- 축어록/STT 텍스트
- 이전 회기 요약

선택 입력:

- 상담 목표
- 심리검사 요약
- 주요 키워드
- 비언어/반언어 메모

### 2.2 입력 정제

- 실명, 학교명, 연락처 등 민감정보 가능성 탐지
- 상담사 메모, 축어록, 이전 회기 요약 분리
- 긴 텍스트를 처리 가능한 입력 구조로 정리
- 입력 형식 정규화

### 2.3 상담 내용 구조화

공통 중간 구조를 생성합니다.

- 주호소 / 주요 이슈
- 회기 주제
- 상담 내용
- 상담자 개입
- 내담자 반응
- 중요한 내담자 발화
- 비언어/반언어 메모
- reflection 후보
- 추후 계획

### 2.4 근거 매핑

각 구조화 항목에 근거 유형을 연결합니다.

- `direct`
- `inferred`
- `counselor_input`
- `previous_context`
- `needs_review`

출처는 다음 기준으로 표시합니다.

- 상담사 메모
- 축어록/STT
- 이전 회기 요약
- 모델 추론
- 상담사 확인 필요

### 2.5 회기요약 초안 생성

상담사가 편집할 수 있는 회기요약 초안을 생성합니다.

- 회기 정보
- 회기 주제
- 주호소 / 주요 문제
- 상담 내용 요약
- 상담자 개입
- 내담자 반응 및 변화
- reflection
- 추후 개입 계획

### 2.6 검증 리포트 생성

검증 리포트는 다음 항목을 포함합니다.

- 입력 근거 있음
- 입력 근거 부족
- AI 추론 가능성
- 민감정보 가능성
- 상담사 직접 판단 필요

### 2.7 상담사 수정 및 확정

상담사는 다음 작업을 수행할 수 있어야 합니다.

- 생성된 섹션 수정
- 문장 삭제 또는 추가
- 민감정보 제거
- 누락된 맥락 추가
- 최종 회기 기록 확정

## 3. MVP V0 제외 범위

이번 MVP에서는 다음 기능을 제외합니다.

- 실시간 상담 지원
- 상담사 수행 평가
- 완전 자동 사례개념화
- AI 슈퍼비전
- 자살/자해 위험 판단
- 원본 음성 저장
- 장기 상담 데이터베이스
- Vector DB/RAG
- 관리자 대시보드
- 예약, 결제, 노쇼 관리
- 정식 HWP 내보내기

## 4. MVP V1 후보

다음 기능은 6월 중순 이후 확장 후보입니다.

- 슈퍼비전 보고서 초안 변환
- 종결 보고서 초안 변환
- 문서 유형별 부족 정보 탐지
- 상담사 맞춤형 회기요약 섹션 설정
- 복사, Markdown, Word 내보내기
- HWP 내보내기 검토
- 전문가 검토 이후 보안 저장 정책 설계

## 5. 프론트 화면 방향

UI는 초기에는 예쁘게 완성하기보다 서비스 흐름을 이해할 수 있게 만드는 것을 우선합니다.

전체 화면 구조:

```text
SessionDraftPage
├── 1. 입력 영역
├── 2. 처리 상태 영역
├── 3. 결과 탭 영역
│   ├── 구조화 결과
│   ├── 회기요약 초안
│   ├── 검증 리포트
│   └── 문서 변환 Preview
└── 4. 상담사 확정 영역
```

처리 상태는 agentic workflow가 보이도록 다음 단계로 표시합니다.

1. 입력 정제 중
2. 상담 내용 구조화 중
3. 근거 연결 중
4. 회기요약 초안 생성 중
5. 검증 리포트 생성 중

결과 탭에는 구조화 결과, 회기요약 초안, 검증 리포트, 문서 변환 preview를 표시합니다.

검증 리포트는 MVP에서 가장 중요한 화면입니다. 입력 근거 있음, 추론 가능성, 민감정보 가능성, 상담사 확인 필요 항목이 분리되어야 합니다.

상담사 확정 영역에는 다음 문구를 표시합니다.

```text
AI 초안은 상담사의 검토 전 최종 기록으로 사용되지 않습니다.
상담사가 수정·확정한 내용만 최종 회기 기록으로 저장됩니다.
```
