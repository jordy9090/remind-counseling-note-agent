# 데모 시나리오 (Presentation Flow)

## 화면 구성

### 메인 화면: SessionDraftPage

좌측 고정 폼 + 우측 3단계 결과 카드

```
┌─────────────────────────────────────────────────────────┐
│ 상담 회기 요약 생성                                       │
├──────────────────┬──────────────────────────────────────┤
│  📋 회기 정보    │  📊 처리 결과                        │
│  입력 폼         │  ├─ 구조화 결과                      │
│                  │  ├─ 회기 요약                       │
│  • 케이스 ID     │  └─ 검증 리포트                     │
│  • 회기번호       │                                    │
│  • 상담사 메모   │  (로딩: 실시간 진행 표시)           │
│  • 축어록       │                                    │
│  • 이전 요약     │  (에러: 빨강 알림박스)              │
│  [생성 버튼]    │                                    │
└──────────────────┴──────────────────────────────────────┘
```

## 시연 시나리오

### 1단계: 입력 준비 (0:00-0:30)
- "오늘 상담 사례를 한 건 보겠습니다. 대학생 진로 상담 케이스입니다."
- 좌측 폼에 `sample_data/session_input_001.json` 데이터 입력
  - 케이스ID: CASE001
  - 회기: 3
  - 상담사 메모: 김지은, 대학생, 진로불안
  - 축어록: 실제 상담 대화
  - 이전요약: 회기 2 정보

### 2단계: 처리 실행 (0:30-1:00)
- "이제 '회기 요약 생성' 버튼을 클릭합니다."
- 클릭 → 로딩 애니메이션 표시 (처리 중...)
- 백엔드: LangGraph 워크플로우 실행
  - structure_node: 축어록 + 메모 → 8필드 구조화
  - summary_node: 구조 → 4필드 요약
  - verification_node: 입력 vs 출력 → 4분류 검증

### 3단계: 결과 표시 (1:00-2:30)

#### 카드 1: 구조화 결과
"먼저 입력된 정보가 어떻게 구조화되었는지 보겠습니다."
- 8가지 필드 전개 (기본정보, 주호소, 목표, ...)
- 각 필드에서 LLM이 핵심 정보를 추출했음을 설명

#### 카드 2: 회기 요약
"이 구조화된 정보를 바탕으로 전문가 수준의 요약을 생성했습니다."
- 상담내용: "강점 기반 진로 탐색"
- 상담자소견: "불안감 감소, 자신감 회복 중"
- 회기요약: 한눈에 보는 3문장 요약
- 추후계획: "인턴십 지원 → 다음 회기 점검"

#### 카드 3: 검증 리포트
"생성된 정보의 신뢰도를 4가지로 분류했습니다."
- 🟢 **근거 있는 항목** (초록)
  - "대학생, 진로 불안" ← 입력에서 직접 확인
- 🟠 **근거 부족** (주황)
  - "자신감 회복" ← 추측/해석 포함 (다음 회기 재확인 필요)
- 🔴 **민감정보** (빨강)
  - "심리적 어려움, 개인 평가" ← 보안/윤리 검토 필요
- 🔵 **판단 필요** (파랑)
  - "행동 변화 가능성" ← 상담사가 직접 평가해야 함

### 4단계: 의의 설명 (2:30-3:00)
"이렇게 자동화된 요약과 검증을 통해..."
- ✅ 상담사의 문서화 시간 단축
- ✅ 일관된 구조로 회기 기록 정리
- ✅ AI의 한계와 신뢰도 명시 (검증 리포트)
- ✅ 상담사의 최종 판단과 승인 프로세스 지원
