# 데모 시나리오

## 1. 데모 목표

Re:mind MVP V0가 상담사 메모, 축어록/STT 텍스트, 이전 회기 요약을 받아 6-agent backend pipeline을 실행하고, React 화면에서 결과를 확인하는 흐름을 보여줍니다.

## 2. 실행 준비

Backend:

```bash
cd backend
uv run uvicorn app.main:app --reload
```

Frontend:

```bash
cd frontend
pnpm dev
```

브라우저:

```text
http://localhost:5173
```

API key 없이 데모하려면 `backend/.env`에 다음을 설정합니다.

```env
USE_STUB=1
```

## 3. 화면 구성

```text
SessionDraftPage
├── 1. 입력 영역
├── 2. 처리 상태
└── 3. 결과 탭
    ├── 구조화 결과
    ├── 회기요약 초안
    ├── 검증 리포트
    ├── 문서 변환 Preview
    └── Raw JSON
```

## 4. 시연 흐름

### 1단계: 입력 준비

`sample_data/session_input_001.json`의 내용을 기준으로 입력합니다.

- 케이스 ID: `CASE001`
- 회기 번호: `3`
- 날짜: `2026-05-17`
- 상담자: `Counselor A`
- 상담사 메모
- 축어록/STT 텍스트
- 이전 회기 요약
- 선택 입력: 상담 목표, 심리검사 요약, 주요 키워드

### 2단계: 생성 실행

`회기요약 초안 생성` 버튼을 클릭합니다.

처리 단계 UI:

1. 입력 정제 중
2. 상담 내용 구조화 중
3. 근거 연결 중
4. 회기요약 초안 생성 중
5. 검증 리포트 생성 중
6. 문서 변환 Preview 생성 중

### 3단계: 구조화 결과 확인

구조화 결과 탭에서 다음 항목을 확인합니다.

- 주호소 / 주요 이슈
- 회기 주제
- 상담 내용
- 상담자 개입
- 내담자 반응
- 중요한 발화
- 비언어/반언어 메모
- reflection 후보
- 추후 계획

각 항목에는 `근거 있음`, `추론`, `상담사 입력`, `확인 필요` 같은 evidence badge가 붙습니다.

### 4단계: 회기요약 초안 확인 및 수정

회기요약 초안 탭에서 각 섹션을 textarea로 수정할 수 있습니다.

- 회기 주제
- 주호소 / 주요 문제
- 상담 내용 요약
- 상담자 개입
- 내담자 반응 및 변화
- reflection
- 추후 개입 계획

### 5단계: 검증 리포트 확인

검증 리포트는 다음으로 분리됩니다.

- 입력 근거 있음
- 입력 근거 부족 / 추론 가능성
- 민감정보 후보
- 상담사 직접 판단 필요

reflection, 사례개념화, 목표 달성 정도는 상담사 확인 필요 영역으로 표시됩니다.

### 6단계: 문서 변환 Preview 확인

문서 변환 Preview 탭에서는 슈퍼비전 보고서와 종결 보고서로 확장할 때 필요한 추가 필드를 확인합니다.

MVP V0에서는 정식 문서 변환/export가 아니라 preview 수준임을 설명합니다.

## 5. 강조할 점

- Re:mind는 상담사를 평가하거나 임상 판단을 대체하지 않습니다.
- 회기요약 초안과 검증 리포트를 통해 상담사의 문서화 부담을 줄이는 도구입니다.
- 입력 근거와 AI 추론, 상담사 확인 필요 영역을 분리합니다.
