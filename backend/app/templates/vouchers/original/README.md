# Supplied voucher packet

`ari-voucher-original.hwpx` is the unmodified blank packet supplied by the user
from Ari Counseling Center on November 4, 2026. It includes the center's own
wording, placeholders, branding, eight-article contract and assessment forms.
It is not represented as the current official government template or an
automatically completed client record.

`ari-voucher-original.pdf` is its twelve-page print rendering, generated locally
with the checksum-verified rhwp 0.8.7 CLI, `--profile print --compat 2024` and
the installed Windows fonts. All pages were inspected for layout and clipping.
No conversion service receives the file at runtime. The original HWPX is never
repacked, edited or regenerated. The manifest pins both complete file hashes.

These assets are served through authenticated, no-store voucher routes. They
are separate from the versioned Form 10/25/26 snapshot templates, so this packet
does not invalidate previously saved or reviewed documents. Replacing a packet
requires generating and verifying its corresponding PDF and updating both hashes.
